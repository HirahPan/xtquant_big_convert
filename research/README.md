# QMT research layer

This directory contains HirahPan's independent QMT research work. It is kept on the `research` branch of the [xtquant_big_convert fork](https://github.com/HirahPan/xtquant_big_convert), separate from the upstream bridge implementation.

## Attribution and boundaries

- Upstream bridge: [litaolemo/xtquant_big_convert](https://github.com/litaolemo/xtquant_big_convert).
- This repository remains a GitHub fork, so the original author and fork relationship stay visible.
- `data-lake/` is HirahPan's research layer. It reads cached market data through the bridge but does not alter upstream bridge code.
- Account credentials, Redis settings, local databases, caches, logs, and generated market data are excluded from Git.

## Contents

- `data-lake/src/`: data-lake implementation and research utilities.
- `data-lake/scripts/`: local operational helpers.
- `data-lake/tests/`: regression tests.
- `data-lake/docs/`: research and operating documentation.
- `REDIS.md`: the optional Redis transport plan for QMT bridge research.

`PROGRESS.md` is regenerated by the daily sync task after it copies current local research files, checks the upstream fork divergence, and pushes a commit only when tracked content changed.
